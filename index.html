1.1 Four Ways to Represent a Function

Key Ideas

  • A function assigns exactly one output to each input in its domain — think of it as a rule or a machine.
  • The same function can be described verbally, with a table of values, with a graph, or with a formula.
  • Domain = the set of allowed inputs. Range = the set of outputs actually produced.
  • For formulas, the domain is usually restricted by things like division by zero, square roots of negatives, or logs of non-positive numbers.
  • Vertical Line Test: a curve represents a function of \(x\) only if every vertical line crosses it at most once.
  • Piecewise functions use different formulas on different intervals — always check which interval \(x\) falls into first.
  • Even function: \(f(-x) = f(x)\), graph symmetric about the \(y\)-axis. Odd function: \(f(-x) = -f(x)\), graph symmetric about the origin. Most functions are neither.
  • A function is increasing on an interval if its outputs rise as \(x\) increases there, and decreasing if outputs fall.

Worked Examples

Example 1 — Domain with a root and a denominator
Find the domain of \(f(x) = \dfrac{\sqrt{5-x}}{x+2}\).
Need \(5 - x \ge 0 \Rightarrow x \le 5\), and \(x \ne -2\) (denominator can't be zero).
Domain: \((-\infty, -2) \cup (-2, 5]\).
Example 2 — Even, odd, or neither
Classify \(h(x) = 3x^3 - 2x\).
\(h(-x) = 3(-x)^3 - 2(-x) = -3x^3 + 2x = -(3x^3-2x) = -h(x)\) → odd.
Example 3 — Evaluating a piecewise function
\(f(x) = \begin{cases} x+1 & x<0 \\ x^2 & x \ge 0\end{cases}\)
\(f(-3)\): since \(-3<0\), use first piece: \(-3+1=-2\).
\(f(0)\): since \(0 \ge 0\), use second piece: \(0^2=0\).
\(f(2) = 2^2 = 4\).

⚠ Common Mistakes

  • Forgetting one of several domain restrictions at once (e.g. checking the square root but not the denominator).
  • Assuming "not even" means "odd" — most functions are neither.
  • Plugging a piecewise input into the wrong piece by misreading a boundary (e.g. treating \(x=0\) as "less than 0").

Practice Problems

  1. Find the domain of \(g(x) = \dfrac{\sqrt{x+4}}{x-1}\).
    Check answer
    \([-4,1)\cup(1,\infty)\)
  2. Determine whether \(p(x) = x^4 - 3x^2 + 1\) is even, odd, or neither.
    Check answer
    Even, since \(p(-x)=p(x)\).
  3. Given \(f(x) = \begin{cases}2x+3 & x\le 1\\ 5-x & x>1\end{cases}\), find \(f(-2)\), \(f(1)\), and \(f(4)\).
    Check answer
    \(f(-2)=-1\), \(f(1)=5\), \(f(4)=1\)
  4. Does the equation \(x^2+y^2=9\) define \(y\) as a function of \(x\)? Explain using the Vertical Line Test.
    Check answer
    No — it's a circle; most vertical lines through the interior cross it twice.
  5. Describe the interval(s) where \(f(x)=(x-2)^2\) is decreasing and where it is increasing.
    Check answer
    Decreasing on \((-\infty,2)\), increasing on \((2,\infty)\).

1.2 Mathematical Models: A Catalog of Essential Functions

Key Ideas

  • Linear: \(f(x)=mx+b\) — constant rate of change \(m\); good for quantities that change by the same amount per unit input.
  • Polynomial: sum of terms \(a_nx^n+\dots+a_0\); the degree drives the overall shape.
  • Power functions \(x^a\): positive-integer powers form even/odd families of curves; \(a=1/n\) gives root functions; \(a=-1\) gives the reciprocal function.
  • Rational functions: ratio of two polynomials; domain excludes wherever the denominator is zero.
  • Algebraic functions: built from polynomials using \(+,-,\times,\div\), and roots.
  • Trigonometric functions are periodic (period \(2\pi\) for sin/cos) and always use radians in calculus; \(-1\le \sin x, \cos x \le 1\).
  • Exponential functions \(b^x\) (\(b>0, b\ne 1\)) grow or decay rapidly; domain is all reals, range is \((0,\infty)\).
  • Logarithmic functions are the inverses of exponential functions.

Worked Examples

Example 1 — Building a linear model
A taxi charges a $20 flat fee plus $3/mile. \(C(x) = 3x+20\). Cost for 15 miles: \(C(15)=3(15)+20=65\), i.e. $65.
Example 2 — Reading a polynomial's basic shape
\(p(x) = -2x^3+5x-1\) has degree 3 (odd degree) and a negative leading coefficient, so it has the general "S-curve" shape of a cubic, flipped compared to \(y=x^3\).
Example 3 — Domain of a rational function
\(r(x) = \dfrac{x+1}{x^2-4}\). Denominator zero at \(x=\pm2\), so domain is all reals except \(2\) and \(-2\).

⚠ Common Mistakes

  • Confusing power functions like \(x^2\) with exponential functions like \(2^x\) — they behave very differently for large \(x\).
  • Forgetting to exclude denominator zeros from a rational function's domain.
  • Using degrees instead of radians in trigonometric calculations.

Practice Problems

  1. A tank starts at 60°F and cools 2°F per hour. Write a linear model and find the temperature after 5 hours.
    Check answer
    \(T(t)=60-2t\); \(T(5)=50°F\)
  2. State the degree of \(q(x) = 4x^5-x^2+7\) and say whether that degree is odd or even.
    Check answer
    Degree 5, odd.
  3. Find the domain of \(r(x) = \dfrac{\sqrt{x}}{x^2-9}\).
    Check answer
    \([0,3)\cup(3,\infty)\)
  4. Classify each: (a) \(f(x)=x^3-2\), (b) \(g(x)=\dfrac{1}{x+1}\), (c) \(h(x)=\sin x\).
    Check answer
    (a) polynomial, (b) rational, (c) trigonometric (transcendental)
  5. Compare the general shapes of \(y=x^4\) and \(y=x^5\) for negative \(x\).
    Check answer
    \(x^4\) stays positive (even power family); \(x^5\) goes negative (odd power family).

1.3 New Functions from Old Functions

Key Ideas

  • Vertical/horizontal shifts: \(f(x)+c\) shifts up, \(f(x)-c\) shifts down, \(f(x-c)\) shifts right, \(f(x+c)\) shifts left (for \(c>0\)).
  • Stretch/shrink/reflect: \(cf(x)\) stretches vertically for \(c>1\); \(f(cx)\) shrinks horizontally for \(c>1\) (opposite of the vertical case); \(-f(x)\) reflects over the \(x\)-axis; \(f(-x)\) reflects over the \(y\)-axis.
  • Arithmetic combinations \((f+g)\), \((f-g)\), \((fg)\), \((f/g)\) have domain equal to the intersection of the two domains (and \(f/g\) also excludes wherever \(g=0\)).
  • Composition: \((f\circ g)(x) = f(g(x))\) — apply \(g\) first, then \(f\). In general \((f\circ g)\ne(g\circ f)\).
  • Domain of \(f\circ g\): all \(x\) in the domain of \(g\) such that \(g(x)\) is in the domain of \(f\).

Worked Examples

Example 1 — Reading transformations
Given \(f(x)=x^2\), describe \(g(x)=f(x-3)+2=(x-3)^2+2\): shift right 3, then up 2.
Example 2 — Composition order matters
\(f(x)=2x-1\), \(g(x)=x^2+3\).
\((f\circ g)(x) = 2(x^2+3)-1 = 2x^2+5\).
\((g\circ f)(x) = (2x-1)^2+3 = 4x^2-4x+4\).
These are different functions — order matters.
Example 3 — Domain of a quotient
\(f(x)=\sqrt{x}\), \(g(x)=x-4\). \(f/g\) needs \(x\ge0\) (domain of \(f\)) and \(x\ne4\) (where \(g=0\)). Domain: \([0,4)\cup(4,\infty)\).

⚠ Common Mistakes

  • Reading \(f(x-c)\) as a shift left instead of right.
  • Forgetting that horizontal stretch/shrink is "backwards" relative to vertical stretch/shrink.
  • Assuming \((f\circ g)(x) = (g\circ f)(x)\) — check both directions separately.
  • Skipping the domain check for compositions involving square roots or denominators.

Practice Problems

  1. Describe the transformations that turn \(y=x^2\) into \(y=-(x+1)^2-4\).
    Check answer
    Shift left 1, reflect over the x-axis, shift down 4 (reflection and vertical shift order can vary — the key transformations are shift left 1, reflect vertically, shift down 4).
  2. If \(f(x)=\sqrt{x}\) and \(g(x)=x+5\), find \((f\circ g)(x)\) and its domain.
    Check answer
    \(\sqrt{x+5}\), domain \(x\ge-5\)
  3. Given \(f(x)=1/x\) and \(g(x)=x-2\), find \((g\circ f)(x)\) and \((f\circ g)(x)\). Are they equal?
    Check answer
    \((g\circ f)(x)=\dfrac{1}{x}-2\); \((f\circ g)(x)=\dfrac{1}{x-2}\). Not equal.
  4. How does the graph of \(y=3f(x)\) differ from \(y=f(x)\)? How about \(y=f(x/3)\)?
    Check answer
    \(3f(x)\): vertical stretch by 3. \(f(x/3)\): horizontal stretch by 3.
  5. For \(f(x)=x^2-1\), \(g(x)=x+1\), find and simplify \((f+g)(x)\), \((f-g)(x)\), \((fg)(x)\).
    Check answer
    \((f+g)(x)=x^2+x\); \((f-g)(x)=x^2-x-2\); \((fg)(x)=(x^2-1)(x+1)=x^3+x^2-x-1\)

1.4 Exponential Functions

Key Ideas

  • \(b^x\) is defined for every real \(x\) when \(b>0\); the usual laws of exponents apply.
  • Graphs all pass through \((0,1)\): if \(b>1\) the function grows; if \(0
  • Great for modeling repeated proportional growth/decay: \(P(t)=P_0\cdot b^{t/k}\) where the quantity multiplies by \(b\) every \(k\) units of time.
  • The number \(e \approx 2.71828\) is the unique base for which the tangent line to \(y=b^x\) at \(x=0\) has slope exactly 1. \(f(x)=e^x\) is the "natural" exponential function.

Worked Examples

Example 1 — Doubling model
A culture starts at 200 and doubles every 3 hours: \(P(t)=200\cdot2^{t/3}\). After 9 hours: \(P(9)=200\cdot2^{3}=1600\).
Example 2 — Exponential vs. polynomial growth
At \(x=5\): \(3^5=243\) but \(5^3=125\). Exponentials eventually overtake polynomials no matter the polynomial's degree.
Example 3 — Simplifying with exponent laws
\(\dfrac{e^2\cdot e^3}{e^4} = e^{2+3-4}=e^1=e\).

⚠ Common Mistakes

  • Confusing exponential growth \(b^x\) with polynomial growth \(x^b\) — these are very different functions.
  • Thinking \(0.5^x\) is somehow linear-like because 0.5 "looks like" a slope; it is decay, not a line.
  • Treating \(e\) as exactly \(2.718\) rather than an irrational number that's only approximated by that decimal.

Practice Problems

  1. A population of 500 grows by a factor of 1.5 every year. Write an exponential model and find the population after 4 years.
    Check answer
    \(P(t)=500(1.5)^t\); \(P(4)=500(1.5)^4=2531.25\)
  2. Which grows faster in the long run, \(f(x)=2^x\) or \(g(x)=x^{10}\)? Explain your reasoning.
    Check answer
    \(f(x)=2^x\) eventually wins — exponential functions always outgrow any fixed power function eventually.
  3. Simplify \(\dfrac{(e^3)^2}{e^4}\).
    Check answer
    \(e^{6-4}=e^2\)
  4. An 80 mg radioactive sample halves every 5 days. Write a decay model and find the amount left after 15 days.
    Check answer
    \(A(t)=80(1/2)^{t/5}\); \(A(15)=80(1/2)^3=10\) mg
  5. True or false: \(e^0=1\). Justify using exponent properties.
    Check answer
    True — any nonzero base raised to the 0 power equals 1, by definition/consistency of exponent rules.

1.5 Inverse Functions and Logarithms

Key Ideas

  • A function has an inverse only if it's one-to-one (passes the Horizontal Line Test).
  • \(f^{-1}\) swaps the domain and range of \(f\); their graphs are reflections of each other across the line \(y=x\).
  • Cancellation equations: \(f^{-1}(f(x))=x\) for \(x\) in the domain of \(f\); \(f(f^{-1}(x))=x\) for \(x\) in the domain of \(f^{-1}\).
  • Caution: \(f^{-1}(x)\) does not mean \(1/f(x)\).
  • \(\log_b x\) is the inverse of \(b^x\): \(\log_b x = y \iff b^y = x\).
  • Log laws: \(\log_b(xy)=\log_b x+\log_b y\); \(\log_b(x/y)=\log_b x-\log_b y\); \(\log_b(x^r)=r\log_b x\).
  • Natural log \(\ln x = \log_e x\); \(e^{\ln x}=x\), \(\ln(e^x)=x\).
  • Inverse trig functions require restricting the original function's domain first (e.g. \(\sin\) restricted to \([-\pi/2,\pi/2]\) before defining \(\arcsin\)).

Worked Examples

Example 1 — Finding an inverse algebraically
Find \(f^{-1}\) for \(f(x)=2x-6\).
Write \(y=2x-6\), solve for \(x\): \(x=\dfrac{y+6}{2}\), then swap variables: \(f^{-1}(x)=\dfrac{x+6}{2}\).
Check: \(f^{-1}(f(x))=\dfrac{(2x-6)+6}{2}=x\). ✓
Example 2 — Solving an exponential equation with logs
Solve \(e^{2x}=10\).
Take \(\ln\) of both sides: \(2x=\ln 10\), so \(x=\dfrac{\ln 10}{2}\approx 1.151\).
Example 3 — Using log laws to expand
\(\ln\!\left(\dfrac{x^3\sqrt{y}}{z}\right) = 3\ln x + \tfrac{1}{2}\ln y - \ln z\).

⚠ Common Mistakes

  • Reading \(f^{-1}(x)\) as the reciprocal \(1/f(x)\) — the \(-1\) is inverse notation, not an exponent.
  • Writing \(\log_b(x+y)\) as \(\log_b x + \log_b y\) — the product law applies to products, not sums.
  • Trying to invert a function that isn't one-to-one without restricting its domain first.
  • Taking the log of a negative number or zero — \(\log_b x\) requires \(x>0\).

Practice Problems

  1. Find \(f^{-1}(x)\) for \(f(x)=\dfrac{x-1}{3}\) and verify with a cancellation equation.
    Check answer
    \(f^{-1}(x)=3x+1\); check: \(f(f^{-1}(x))=\dfrac{(3x+1)-1}{3}=x\). ✓
  2. Is \(f(x)=x^2\) one-to-one on \((-\infty,\infty)\)? On \([0,\infty)\)? What is the inverse on the restricted domain?
    Check answer
    Not one-to-one on all reals (fails the Horizontal Line Test); it is one-to-one on \([0,\infty)\), where \(f^{-1}(x)=\sqrt{x}\).
  3. Evaluate without a calculator: \(\log_2 32\), \(\log_{10} 0.001\), \(\ln e^7\).
    Check answer
    \(\log_2 32=5\); \(\log_{10}0.001=-3\); \(\ln e^7=7\)
  4. Solve for \(x\): \(5\cdot 3^{x}=45\).
    Check answer
    \(3^x=9\Rightarrow x=2\)
  5. Write as a single logarithm: \(2\ln x + \ln y - \tfrac{1}{2}\ln z\).
    Check answer
    \(\ln\!\left(\dfrac{x^2 y}{\sqrt{z}}\right)\)
